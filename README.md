# Melô

Rascunho responsivo de uma loja de discos de vinil.

## Arquivos

- `index.html` — estrutura da loja
- `styles.css` e `melo-overrides.css` — identidade visual e adaptação para celular
- `app.js` — catálogo, filtros, sacola e checkout demonstrativo

Abra `index.html` no navegador para visualizar o site. Os produtos e preços são exemplos; frete e pagamento ainda não estão conectados a serviços reais.
